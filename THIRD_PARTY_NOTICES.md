## KataGo

KataGo is an independently developed Go analysis engine released under the [MIT License](https://github.com/lightvector/KataGo/blob/master/LICENSE). Users install a KataGo executable from Homebrew or the official releases and select it in QiDao. See the official [KataGo project](https://github.com/lightvector/KataGo), [Analysis Engine documentation](https://github.com/lightvector/KataGo/blob/master/docs/Analysis_Engine.md), and [GTP extensions documentation](https://github.com/lightvector/KataGo/blob/master/docs/GTP_Extensions.md).

## KataGo network weights

KataGo network weights are not included in this source release. Users download a compatible `.bin.gz` file from the [KataGo official network page](https://katagotraining.org/networks/) and select it in QiDao. The applicable network-weight notice is in [katago/NETWORK_LICENSE.md](katago/NETWORK_LICENSE.md).

## ONNX vision models

`vision/models/board_locator.onnx` and `vision/models/intersection_classifier.onnx` are assets authored by this fork's QiDao contributors and released under the repository's [MIT License](LICENSE.md). They were trained from random initialization using synthetic board data generated by `vision/ml/synthetic_data.py`; the training entry point is `vision/ml/train.py`. No third-party model weights or datasets were used.
